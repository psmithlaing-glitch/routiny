# Routiny V1.2 Prototype

## Added in V1.2
- "Just today" is now a true one-day activity.
- Every day / weekdays / weekends / custom days now filter activities by the selected date.
- Today screen can move to previous/next days.
- Schedule has a simple 7-day date picker.
- Completion history is date-based, so recurring habits reset correctly each day.
- Stats use recorded completion history.
- Added Skip today and Undo.
- Added PWA manifest, service worker and app icons.
- Fixed dark-mode persistence.

## Important
Browser notification permission is only the permission step. True scheduled iPhone Web Push needs Routiny to be hosted on HTTPS and connected to a push service/backend. That is the next deployment step.

## Run
Use VS Code + Live Server and open index.html.
